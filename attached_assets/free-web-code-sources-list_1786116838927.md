## Learn + reference

- [MDN Web Docs](https://developer.mozilla.org/en-US/) - Free reference. HTML, CSS, JavaScript, accessibility, APIs, examples, and compatibility tables. MDN content/code licensing applies.

- [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) - Free curriculum. Structured front-end learning path with examples and exercises.

- [MDN content repository](https://github.com/mdn/content) - Open-source documentation repo. Source repository for MDN content; review the repository's content/code licenses.

- [web.dev Learn](https://web.dev/learn) - Free official courses. Google's structured courses for HTML, CSS, JavaScript, accessibility, performance, PWA and more.

- [web.dev Learn CSS](https://web.dev/learn/css) - Free official course. Evergreen CSS course and reference.

- [1-Line Layouts](https://1linelayouts.com/) - Free demos. Ten compact modern CSS layout and sizing techniques with editable demos.

- [W3C CSS](https://www.w3.org/Style/CSS/) - Open-web standard reference. CSS specifications, working-group material, and official links.

- [WHATWG HTML Living Standard](https://html.spec.whatwg.org/) - Open standard. Authoritative living HTML standard.

- [WAI Tutorials](https://www.w3.org/WAI/tutorials/) - Free accessibility guidance. Practical accessibility patterns from W3C WAI.

- [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) - Free accessibility patterns. Accessible widget patterns, keyboard behavior, and examples.

- [Can I Use](https://caniuse.com/) - Free compatibility reference. Browser support tables for web platform features.

- [JavaScript.info](https://javascript.info/) - Free learning site. Deep JavaScript tutorials; material has its own content license, so do not assume unrestricted republication.

- [Patterns.dev](https://www.patterns.dev/) - Free pattern reference. Modern web design, rendering, and JavaScript pattern explanations.

- [W3Schools](https://www.w3schools.com/) - Free learning + examples. Tutorials and Tryit examples; W3Schools content copyright/terms apply.

- [W3Schools Tryit](https://www.w3schools.com/tryit/) - Free playground. Browser-based HTML/CSS/JS examples and exercises.

- [CSS-Tricks](https://css-tricks.com/) - Free articles + demos. Front-end tutorials and demos; individual article/code licensing applies.

- [A11Y Project](https://www.a11yproject.com/) - Free accessibility resource. Community-driven accessibility checklist and articles.

- [webhint](https://webhint.io/) - Open-source guidance/tooling. Checks accessibility, compatibility, performance and web best practices.
